# DayFlow-Habit-Tracker
DayFlow is a local-first, AI-assisted habit and study-plan tracker. It runs in the browser as a PWA, and it also has an Electron desktop build.  Plan: you add habits by hand (checkbox, quantity or duration, daily or weekly) or import a PDF roadmap. The AI turns the PDF into daily tasks, and a built-in fallback does the same without AI.
